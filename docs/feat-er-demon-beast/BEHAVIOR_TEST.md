# c0010 行为 v3 / DLL 0.3.0 人工测试

本轮候选针对锁定移动方向、连段抢断、F7/到期等待、兽体登场退场、相机。离线检查通过不等于实机通过；本轮不自动启动游戏。

## 测试顺序

使用 DLL 目录的 Start-C0010Test.cmd 重新启动游戏，让 DLL/HKS/Behbnd 同时刷新。仍用你的 ER0000.Shiki。每轮单独测试一项，平坦处先试。

1. **登场/退场**：F6 后先别按动作键，观察兽体是否播放登场、然后可以操作；站立时 F7，观察退场后恢复。15 秒从登场完成后开始。
2. **锁定方向**：F6 后锁定一个目标，分别短按 W/A/S/D，再左右交替。应为前/左/后/右对应运动；取消锁定再检查原先移动转向。若哪一方向不符，请报告方向、兽体朝向和实际位移。
3. **连段窗口**：轻击起手马上连点，不能从起手帧不断重播；继续在挥击后半段按轻击，应能接后续段。分别试轻接重、重接重、闪避后轻击；过早且未被游戏队列保留的点击可能不出下一招，先区分提前打断与漏接。
4. **F7 等待**：重击刚起手时按 F7，然后继续点攻击。应完成这一招，拒绝新增动作，播放退场，再还原。F6/F7 不应在等待期间创建新兽体。
5. **到期等待**：另一轮在可操作后约第 14 秒起手重击，不按 F7。应完成当前动作再退场，不在第 15 秒硬切。
6. **镜头与重复使用**：观察未锁定、锁定时是否拉远/抬高，解除后是否回到原镜头；最后连续完成三轮 F6/F7，检查实体消失和下一轮可进入。

请按“锁定方向 / 连段 / F7 等待 / 到期等待 / 登场退场 / 镜头”反馈。不需要这轮验收伤害数值。

## 已知边界

- 本次是 c0010 自带 Event20000/20010 的兽体登场/退场；玩家 c0000 起手、完整变形特效、声音与透明度演出仍未移植。为避免 NR 专用引擎事件，这两段的 TAE 暂停执行，动画和完成回调保留。
- 进入阶段 F7 保留取消加载/紧急恢复；正常等待规则针对已经能操作后的攻击。
- 等待结束超过 8 秒会以故障执行紧急恢复，日志 behavior_finish_timeout；这不是正常完成。如果发生卡住，等约 10 秒后退出并收集日志，不必反复按键。
- 当前相机配置 camera_distance=7.0、camera_height=2.6，分别是米制距离和观察点高度的最低值；修改后需重启。特殊目标/动画专用镜头仍可能需要适配。
- 衔接下界按当前动画资源和正常播放速度校验；变速/停帧下的精确窗口仍待验证。
