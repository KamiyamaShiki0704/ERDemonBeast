# c0010 行为适配包 v2：人工测试

DLL 仍为 0.2.2。本轮只更新已绑定的 d0010.hks，补齐起手 Wait 标志，修复裸文件名/反斜线路径初始化。其余资源沿用 v1；三张名字表无需再补项。玩法尚待人测。

## 本轮候选行为

- 地面轻击 3000→3001→3002→3003→3000；重击 3005→3007；左右手基础输入到 3030/3035。
- 闪避按钮候选动作 6000，闪避后轻击 3010。当前按下触发，不宣称完整的长按冲刺/松键闪避语义。
- 连段消费 ER 的取消请求窗口，不强制截断任何动作。每次松开再按触发一次，按住不会重复重启动作。
- 精力不足拒绝出招；按原版 StaminaComboResetTest 标记决定是否回到首段。
- Jump/ULTRA、跳跃攻击、完整移动动画修正、伤害/碰撞/无敌帧、完整 NR TAE 转换尚未完成。注册了这些名称不代表功能已经实现。

## 测试顺序

1. 完全退出旧游戏，通过本目录 Start-C0010Test.cmd 启动，确保本次重新读取 GA 资源。到平坦安全处，不必找敌人。
2. F6 变身，站定后单击轻攻击键（默认鼠标左键）。若出招，松开再点两三次，观察衔接；F7 解除。
3. 再 F6，先站立、再移动时各短按并松开闪避键（默认空格），观察是否出现兽体闪避；F7 解除。当前仍为按下触发的最小侧步。
4. 再 F6，移动中点轻攻击，观察是否出招、是否能回到移动、F7 是否正常。每轮分开，避免 15 秒到期干扰判断。
5. 退出游戏后可运行 Collect-C0010Logs.cmd。若无反应，不必反复尝试。

请反馈“站立攻击 / 移动攻击 / 闪避 / F7 恢复”四项结果。伤害数值不作为本轮通过项。

新脚本日志为 DLL 目录下 Saved/er-demon-beast/c0010-hks-v2.log，每个脚本实例最多 80 行，记录 loaded、Update、ExecAIAction、request/stamina/exists 和 fired。fired=3000/6000 只证明脚本发了事件，不能独立证明动画播放或伤害。若 Lua IO 不可用，文件可能不生成，不能单凭“无文件”判定脚本未加载。

## 回滚

完全退出 ER 后运行 Restore-C0010Behavior.cmd（调用 Manage-C0010Behavior.ps1 -Mode Restore）。恢复安装前四个已有文件并移除本包新增的 d0010.hks。原版 c0010.hks、公用 c9997.hks、anibnd、regulation 和 DLL 均不在本包恢复目标中。

脚本先校验全部现有文件与备份哈希。安装后若你修改过三张名字表或 Behbnd，它会拒绝覆盖，以免丢掉你的后续改动。精确备份目录在 behavior-deployment.json。
