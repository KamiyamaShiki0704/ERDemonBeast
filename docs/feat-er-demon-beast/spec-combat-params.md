# c0010 战斗参数移植规格

用户请求检查被覆盖的 regulation，并进一步移植 c0010 的其他参数。缺失的 NpcParam / NpcThinkParam 两行已经恢复。用户于 2026-09-25 回复“按此范围移植并安装”，确认本文范围、Probe 前置/输入/预期、5 秒/3 次/3 秒等阈值、排除项和人工验收职责；本稿据此基线化为 1.0。

## 预期行为与边界

- CP-001：当 c0010 当前已适配动作产生攻击通知时，应使用 c0010 对应攻击、碰撞和子弹数据；命中范围内可受伤敌人时产生伤害。尽量保留 NR 的可兼容数值，不承诺跨游戏最终伤害一致，不做平衡调参。
- CP-002：重击、跳跃攻击和战技等原动画关联的冲击波应具有完整参数引用；只验证当前输入适配已能触发的动作。参数存在不代表新增按键或完整招式已接通。
- CP-003：保持当前已通过的移动、连段窗口、闪避、登场和解除流程；战技仍按现有原版通知解除，正常解除仍等待动作结束。
- CP-004：所有不属于本次清单的现有参数必须保持；共用已有参数沿用当前 ER 内容，不全局替换成 NR 内容。备份与原子安装，并提供可追溯离线证据。
- CP-005：新增效果采用 ER 可表达语义。保留普通治疗参数及其已有视觉引用；不承诺 NR 遗物触发机制可用。NR 专有不死/复活、70%减伤、遗物/职业/钩爪能力、专用大招硬直和蹬墙玩法不纳入本轮。不引入同数值异语义状态或分类。
