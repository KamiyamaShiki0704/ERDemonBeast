# 共用生命与受击恢复

用户报告兽体生命未与玩家关联、受击后出现Pose且不能操作；明确选择共用当前/最大生命、归零正常死亡，并回复“按这组规则实现”确认下面验收。

- HP-001：进入时继承玩家当前/最大生命，不补满；解除后保留剩余生命，不回滚进入快照。
- HP-002：活动期间兽体受伤/治疗反映到玩家；玩家自身持续效果造成的生命变化不能被兽体旧值覆盖；同一变化不得重复计算。
- HP-003：任一共享生命归零应保持零生命，解除本体控制保护并交回玩家正常死亡，不以解除复活。
- HIT-001：不能发送 c0010 不存在的普通受击动画。已有合法特殊受击仍沿用原生动作；受击打断待激活攻击后，应能恢复输入，正常解除不得抢断尚未完成的受击。

| Probe | 前置/输入 | 预期 | 阈值与排除 |
|---|---|---|---|
| HP-P01 | 离线重放当前/最大生命不相等的玩家进入，以及伤害、治疗、重复帧、解除、重新进入 | 继承准确；变化只计算一次；退出不还原旧生命 | 整数生命精确一致；无游戏运行声明 |
| HP-P02 | 单机平地、存活未骑乘，半血变身，承受普通伤害，再接受一次可用治疗并解除；重复3次 | 不补血、不吞伤害、不重复扣血；解除保持结果 | 实机血条刷新差异≤0.25秒；用户验收 |
| HP-P03 | 离线归零/同时治疗；人工在安全测试场景让兽体生命归零 | 零生命不被治疗或解除覆盖；本体正常死亡 | 控制保护解除/交回玩家≤3秒；死亡动画时长沿用ER；用户验收死亡流程 |
| HIT-P01 | 用真实HKS和资源表重放轻/中/重受击分派、待激活动作被受击打断、受击中解除 | 无不存在动画分派；回到正常节点后输入恢复；受击未结束不播放退场 | 离线逻辑检查；实机验证无Pose/无永久输入锁 |

联机、切图、坠落和特殊抓取死亡、所有异常效果逐项兼容、伤害平衡不在本轮。旧攻击/闪避/连段和正常解除规格继续有效。最终PASS由用户给出。
