# c0010 动作取证（0.2.2）

这是诊断版，攻击映射尚未修复。F6/F7、15 秒到期和实体清理仍沿用原逻辑。

1. 完全退出旧游戏后，用 dll/demon_beast/Start-C0010Test.cmd 启动。它加载该目录最新 DLL，使用你的 ER0000.Shiki 并先备份；进入平坦安全位置。
2. F6 变身后，松开所有按键约一秒。鼠标左键按住一秒后松开一秒，重复一次；接着右键按住一秒后松开一秒，再试 Shift+左键一秒。最后按 F7。各输入分开，不必攻击敌人。
3. 第二轮 F6 后只测试移动、停止、一次空格，再 F7。记录停止后是否仍滑行、是否有攻击动作、是否能正常解除。
4. 退出游戏，双击 Collect-C0010Logs.cmd。告诉我“已测”及看到的表现即可，日志可直接从本机读取。如果改过攻击键位，请同时写明实际按键。

已改用每个活动 FrameEnd 取证，无需手动启动 Case。每轮日志在 Saved/er-demon-beast/<run>/frames.jsonl；专用启动器的日志在 manual-runs/<run> 内。收集脚本同时覆盖两种启动方式，生成 action-report.json 与日志 ZIP，不包含存档或 DLL。

如果用自己的加载方式，请确保加载的是 dll/demon_beast/er_demon_beast.dll 的 0.2.2，旁边配置 action_trace=true，并仅加载一份本 DLL。不要复用上次 manual-runs 的旧 DLL 副本。

本版只记录活动且游戏在前台时的鼠标左右键、Shift、Ctrl、Space 状态及既有角色动作字段，不记录文本输入。FrameEnd 可能看到已被消费后的请求，因此零值不单独代表输入从未到达。伤害与完整连段不在这次测试范围内。
